# คู่มือติดตั้ง AMN SURE บน cPanel (subdomain crmsure.amnsure.co.th)

ระบบ ลูกค้า · สาขา · เครื่อง · การขาย · บริการ ตามสเปก `SURE-ClaudeCode-Prompt.md`
ใช้เวลาประมาณ 20 นาที ทำผ่านหน้า cPanel ทั้งหมด ไม่ต้องใช้ SSH/Terminal

## สิ่งที่ต้องมี

- subdomain `crmsure.amnsure.co.th` (โฟลเดอร์ `public_html/crmsure.amnsure.co.th`)
- PHP 7.4 ขึ้นไป (แนะนำ 8.1 หรือใหม่กว่า) และ MySQL/MariaDB ของ cPanel
- ไฟล์ `amnsure-sure-v1.1.1.zip`
- กล่องอีเมลสำหรับส่งอีเมลของระบบ เช่น `noreply@amnsure.co.th` (สร้างในขั้นที่ 2.1)

> **ถ้าเคยอัปโหลด CRM v1 (`amnsure-crm-v1.0.0.zip`) ไว้ใน subdomain นี้แล้ว** — AMN SURE จะมาแทนที่บน subdomain เดียวกัน
> ให้ทำขั้นที่ 0 ก่อน ส่วนฐานข้อมูลของ CRM v1 (`amnsureco_crm`) ไม่ถูกแตะ — ระบบใหม่ใช้ฐานข้อมูลแยก

## ขั้นที่ 0 — (เฉพาะกรณีมี CRM v1 อยู่แล้ว) ย้ายไฟล์เดิมออก

1. cPanel → **File Manager** → เปิด `public_html/crmsure.amnsure.co.th`
2. **Settings** (มุมขวาบน) → ติ๊ก **Show Hidden Files (dotfiles)** → Save
3. สร้างโฟลเดอร์ใหม่นอก public_html เช่น `/home/amnsureco/crm-v1-backup` แล้วย้าย (Move) ไฟล์ทั้งหมดของ CRM v1 ไปไว้ที่นั่น
   (`index.php`, `install.php`, `.htaccess`, `robots.txt`, `app/`, `assets/`, `storage/`) — **เหลือ `php.ini` ของโฮสต์ไว้ที่เดิม**

## ขั้นที่ 1 — ตั้งเวอร์ชัน PHP ของ subdomain

1. cPanel → **MultiPHP Manager** (หรือ **Select PHP Version**)
2. ติ๊ก `crmsure.amnsure.co.th` → เลือก PHP **8.1 ขึ้นไป** → **Apply**
3. ถ้าใช้หน้า **Select PHP Version** ให้ตรวจว่า extension `pdo_mysql` และ `mbstring` ถูกติ๊กอยู่

## ขั้นที่ 2 — สร้างฐานข้อมูลใหม่ (แยกจากเว็บหลักและระบบอื่นทั้งหมด)

AMN SURE ต้องมี **ฐานข้อมูลของตัวเอง + ผู้ใช้ฐานข้อมูลของตัวเอง** ห้ามใช้ร่วมกับเว็บหลัก `amnsure.co.th`,
หน้า admin ของเว็บ, CRM v1 หรือระบบอื่นใดในโฮสต์นี้ — ถ้าระบบใดระบบหนึ่งมีช่องโหว่ จะไม่ลามไปถึงข้อมูลของอีกระบบ

1. cPanel → **MySQL® Database Wizard**
2. ตั้งชื่อฐานข้อมูล `sure` → ได้ชื่อเต็ม `amnsureco_sure` (**สร้างใหม่** ห้ามเลือกฐานข้อมูลที่มีอยู่แล้ว)
3. สร้างผู้ใช้ฐานข้อมูล **ใหม่** `sureuser` → ได้ `amnsureco_sureuser` กด **Password Generator** แล้ว **คัดลอกรหัสผ่านเก็บไว้**
   (ห้ามใช้ผู้ใช้ฐานข้อมูลของเว็บหลัก เช่นที่อยู่ใน `wp-config.php` และห้ามใช้ชื่อผู้ใช้/รหัสผ่านหลักของ cPanel)
4. หน้าให้สิทธิ์: ติ๊ก **ALL PRIVILEGES** → **Make Changes** (สิทธิ์นี้มีผลเฉพาะฐานข้อมูล `amnsureco_sure`)
5. ตรวจ: cPanel → **MySQL® Databases** → ตาราง "Current Databases" แถว `amnsureco_sure` ต้องมีผู้ใช้ `amnsureco_sureuser` อยู่คนเดียว
   และ `amnsureco_sureuser` **ต้องไม่ปรากฏ** ในแถวของฐานข้อมูลอื่น (ถ้ามี กดไอคอนลบผู้ใช้ออกจากฐานข้อมูลนั้น)

> จดไว้ 3 อย่าง: ชื่อฐานข้อมูล, ชื่อผู้ใช้ฐานข้อมูล, รหัสผ่าน (ใช้ในขั้นที่ 5)
>
> ตัวติดตั้งตรวจให้อัตโนมัติ: **ไม่ยอมติดตั้ง** ถ้าฐานข้อมูลมีตารางอยู่แล้ว หรือถ้าผู้ใช้ฐานข้อมูลเข้าถึงฐานข้อมูลอื่นได้
> หลังติดตั้งแล้ว ถ้า `app/config.php` ถูกแก้ให้ชี้ไปฐานข้อมูลอื่น ระบบจะหยุดทำงานทันทีโดยไม่แตะตารางของฐานข้อมูลนั้น

## ขั้นที่ 2.1 — สร้างกล่องอีเมลสำหรับส่งลิงก์และรหัสยืนยัน

ระบบส่งอีเมล 2 แบบ: **ลิงก์ตั้งรหัสผ่าน** (ครั้งแรก) และ **รหัสยืนยัน 6 หลัก** (ทุกครั้งที่เข้าสู่ระบบ)

1. cPanel → **Email Accounts** → **Create** → ชื่อ `noreply` (ได้ `noreply@amnsure.co.th`) ตั้งรหัสผ่าน → **คัดลอกรหัสผ่านเก็บไว้**
2. ที่บัญชีนั้น กด **Connect Devices** → ดูหัวข้อ **Outgoing Server** จดไว้: ชื่อเซิร์ฟเวอร์ (เช่น `mail.amnsure.co.th`) และ SMTP Port (ปกติ **465**)
3. cPanel → **Email Deliverability** → ถ้า `amnsure.co.th` ขึ้นว่ามีปัญหา กด **Repair** (ตั้ง SPF/DKIM) — ไม่ทำ อีเมลมักตกไปอยู่ในจดหมายขยะของ `amn.co.th` / `astracom.co.th`

## ขั้นที่ 3 — อัปโหลดไฟล์

1. File Manager → เปิด `public_html/crmsure.amnsure.co.th` (เปิด Show Hidden Files ไว้ เพื่อให้เห็น `.htaccess`)
2. **Upload** → เลือก `amnsure-sure-v1.1.1.zip` → รอเสร็จ → กลับไปที่โฟลเดอร์
3. คลิกขวาที่ zip → **Extract** → แตกลงใน `public_html/crmsure.amnsure.co.th` → ลบไฟล์ zip ทิ้งได้
4. ตรวจว่า `index.php`, `install.php`, `.htaccess`, `app/`, `assets/`, `storage/` อยู่ **ชั้นเดียวกับ `php.ini`** (ถ้าไปอยู่ในโฟลเดอร์ย่อยอีกชั้น ให้ย้ายขึ้นมา)

## ขั้นที่ 4 — เปิด HTTPS (ทำก่อนติดตั้ง)

cPanel → **SSL/TLS Status** → ติ๊ก `crmsure.amnsure.co.th` → **Run AutoSSL** → รอจนขึ้นแม่กุญแจสีเขียว

## ขั้นที่ 5 — รันตัวติดตั้ง

1. เปิด **https://crmsure.amnsure.co.th/install.php**
2. ส่วน "ตรวจสอบเซิร์ฟเวอร์" ต้องเป็น ✅ ทั้งหมด
3. **ฐานข้อมูล**: Host = `localhost`, ชื่อฐานข้อมูล / ผู้ใช้ / รหัสผ่าน จากขั้นที่ 2
4. **ที่อยู่เว็บ**: `https://crmsure.amnsure.co.th/` (ใช้สร้างลิงก์ในอีเมล)
5. **การส่งอีเมล**: วิธีส่ง = SMTP · อีเมลผู้ส่ง = `noreply@amnsure.co.th` · SMTP host / Port จากขั้นที่ 2.1 · การเข้ารหัส = SSL (port 465)
   · ชื่อผู้ใช้ SMTP = `noreply@amnsure.co.th` · รหัสผ่านอีเมลจากขั้นที่ 2.1
6. **บัญชี Manager**: ตั้งไว้ให้แล้ว 2 คน — `buranon@amn.co.th` และ `pongsak@astracom.co.th` (แก้ชื่อได้)
7. กด **ติดตั้ง** → ขึ้น "✅ ติดตั้งสำเร็จ" และ "✅ … — ส่งแล้ว" ของ Manager แต่ละคน

ตัวติดตั้งสร้างตารางทั้งหมด + รายการตัวเลือกตามสเปกหัวข้อ 10 + VAT 7% และใช้ได้ครั้งเดียว (ลบไฟล์ `install.php` ทิ้งหลังติดตั้งก็ได้)
ถ้าขึ้น "❌ ส่งไม่สำเร็จ" ดูหัวข้อ "อีเมลไม่มา" ด้านล่าง
ระบบเริ่มต้นแบบ **ว่าง ไม่มีข้อมูลลูกค้า** — ข้อมูลตัวอย่างในสเปกหัวข้อ 11 ใช้สำหรับทดสอบเท่านั้น ไม่รวมอยู่ในไฟล์ zip

## ขั้นที่ 6 — บังคับใช้ HTTPS

File Manager → คลิกขวา `.htaccess` → **Edit** → เลื่อนลงล่างสุด ลบ `#` หน้า 3 บรรทัดนี้ → Save

```
RewriteEngine On
RewriteCond %{HTTPS} !=on
RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
```

## ลำดับการกรอกข้อมูล

ลูกค้า → สาขา → เครื่อง → การขาย → รับชำระเงิน / บริการ (ติดตามลูกค้าบันทึกได้ตั้งแต่มีลูกค้า)
ฟอร์มเพิ่มข้อมูลเติม **รหัสถัดไป** ให้อัตโนมัติ — กดบันทึกได้เลย ระบบตรวจรูปแบบและรหัสซ้ำอีกครั้งตอนบันทึก

## อีเมลไม่มา / ส่งอีเมลไม่ได้

1. ดูในจดหมายขยะ (Junk/Spam) ก่อน — ถ้าอยู่ในนั้น ทำขั้นที่ 2.1 ข้อ 3 (Email Deliverability)
2. ดูไฟล์ `storage/logs/app-ปี-เดือน.log` ค้นคำว่า `MAIL` จะเห็นสาเหตุ เช่น รหัส SMTP ผิด หรือเชื่อมต่อไม่ได้
3. แก้การตั้งค่าใน `app/config.php` ส่วน `'mail'` (File Manager → คลิกขวา → Edit) แล้วลองใหม่
   — ใช้ SMTP ไม่ได้เลย: เปลี่ยน `'transport' => 'smtp'` เป็น `'transport' => 'mail'` (ใช้ระบบส่งอีเมลของโฮสต์)
4. **ฉุกเฉิน** (อีเมลเสียแต่ต้องเข้าระบบด่วน): ใน `app/config.php` เปลี่ยน `'email_2fa' => true` เป็น `false`
   = เข้าด้วยอีเมล + รหัสผ่านอย่างเดียวชั่วคราว **แก้อีเมลได้แล้วต้องเปลี่ยนกลับเป็น `true` ทันที**

## อัปเกรดจากเวอร์ชัน 1.0.0 (ถ้าเคยติดตั้งไว้แล้ว)

1. อัปโหลดไฟล์เวอร์ชันใหม่ทับ (ยกเว้น `app/config.php` และ `storage/`) — ระบบเพิ่มตาราง/คอลัมน์ให้เองตอนเปิดหน้าเว็บครั้งแรก
2. แก้ `app/config.php` เพิ่ม 4 ค่านี้ก่อนบรรทัด `);` สุดท้าย (แก้ค่าตามขั้นที่ 2.1):
   ```php
     'base_url' => 'https://crmsure.amnsure.co.th/',
     'app_key' => 'ใส่ตัวอักษรสุ่มยาว 40 ตัวขึ้นไป',
     'mail' => ['transport' => 'smtp', 'host' => 'mail.amnsure.co.th', 'port' => 465, 'encryption' => 'ssl',
                'username' => 'noreply@amnsure.co.th', 'password' => 'รหัสอีเมล', 'from' => 'noreply@amnsure.co.th', 'from_name' => 'AMN SURE'],
     'email_2fa' => true,
   ```
3. ทุกบัญชีต้องมีอีเมล (Manager ใส่ให้ในหน้าแก้ไขผู้ใช้) — บัญชีที่ไม่มีอีเมลจะเข้าสู่ระบบไม่ได้เพราะรับรหัสยืนยันไม่ได้

## สำรองข้อมูล (Backup) — ทำอย่างน้อยสัปดาห์ละครั้ง

1. **ฐานข้อมูล**: cPanel → **Backup** → "Download a MySQL Database Backup" → คลิก `amnsureco_sure`
2. **ไฟล์ตั้งค่า**: File Manager → ดาวน์โหลด `app/config.php` (มีรหัสฐานข้อมูล — เก็บเป็นความลับ)

ถ้าโฮสต์มี **JetBackup** ใช้กู้คืนย้อนหลังได้อีกทาง

## อัปเดตเป็นเวอร์ชันใหม่

สำรองข้อมูลก่อน แล้วอัปโหลดไฟล์เวอร์ชันใหม่ทับได้เลย **ยกเว้น** `app/config.php` และโฟลเดอร์ `storage/` (ห้ามลบ/ทับ)

## ความปลอดภัยที่ระบบทำให้แล้ว

- ต้องล็อกอินทุกหน้า ไม่มีหน้าสมัครสมาชิก บัญชีสร้างโดย Manager ด้วยอีเมลเท่านั้น — แต่ละคนตั้งรหัสผ่านเองจากลิงก์ในอีเมล
- **ยืนยัน 2 ขั้นตอน**: ทุกครั้งที่เข้าสู่ระบบต้องใส่รหัส 6 หลักที่ส่งไปทางอีเมล (รหัสหลุดอย่างเดียวเข้าไม่ได้)
- ระบบเก็บเฉพาะค่า hash ของลิงก์และรหัสยืนยัน ลิงก์ใช้ได้ครั้งเดียว รหัสหมดอายุใน 10 นาที ผิดได้ 5 ครั้ง
- สิทธิ์ตรวจที่ฝั่ง server ทุกหน้า ทุก action และทุก export; ข้อมูลพนักงานคำนวณโดยไม่อ่านตารางต้นทุนเลย
- ปิดบัญชี/เปลี่ยนสิทธิ์/รีเซ็ตรหัส มีผลทันที; ใส่รหัสผิด 5 ครั้งล็อก 15 นาที; ไม่ใช้งาน 8 ชั่วโมงออกจากระบบเอง
- ทุกแถวเก็บ "บันทึกโดย / แก้ไขล่าสุดโดย" พร้อมเวลา
- โฟลเดอร์ `app/` (โค้ด + รหัสฐานข้อมูล) และ `storage/` เปิดผ่านเว็บตรง ๆ ไม่ได้; ไม่ให้ Google เก็บหน้าเว็บ (noindex)
- **แยกจากเว็บหลักและระบบอื่น**: ฐานข้อมูล + ผู้ใช้ฐานข้อมูลของตัวเอง (ตัวติดตั้งบังคับ), ไฟล์อยู่ในโฟลเดอร์ของ subdomain นี้เท่านั้น,
  cookie เข้าสู่ระบบผูกกับ `crmsure.amnsure.co.th` อย่างเดียว (`__Host-`) — เว็บหลักหรือ subdomain อื่นอ่านหรือปลอม cookie นี้ไม่ได้
