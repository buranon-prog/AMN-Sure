# คู่มือติดตั้ง AMN Sure CRM บน cPanel (subdomain crmsure.amnsure.co.th)

ใช้เวลาประมาณ 20–30 นาที ทำผ่านหน้า cPanel ทั้งหมด ไม่ต้องใช้ SSH/Terminal

## สิ่งที่ต้องมี

- subdomain `crmsure.amnsure.co.th` (โฮสต์สร้างไว้แล้ว โฟลเดอร์คือ `public_html/crmsure.amnsure.co.th`)
- PHP 7.4 ขึ้นไป (แนะนำ 8.1 หรือใหม่กว่า) และ MySQL/MariaDB ซึ่ง cPanel มีให้อยู่แล้ว
- ไฟล์ `amnsure-crm-v1.0.0.zip`

---

## ขั้นที่ 1 — ตั้งเวอร์ชัน PHP ของ subdomain

1. cPanel → **MultiPHP Manager** (หรือ **Select PHP Version**)
2. ติ๊ก `crmsure.amnsure.co.th` → เลือก PHP **8.1 ขึ้นไป** → **Apply**
3. ถ้าใช้หน้า **Select PHP Version** ให้ตรวจว่า extension เหล่านี้ถูกติ๊กอยู่: `pdo_mysql`, `mbstring`, `fileinfo`

## ขั้นที่ 2 — สร้างฐานข้อมูล

1. cPanel → **MySQL® Database Wizard**
2. ตั้งชื่อฐานข้อมูล เช่น `crm` → ระบบจะได้ชื่อเต็มเป็น `amnsureco_crm`
3. สร้างผู้ใช้ฐานข้อมูล เช่น `crmuser` → ได้ `amnsureco_crmuser` กด **Password Generator** แล้ว **คัดลอกรหัสผ่านเก็บไว้**
4. หน้าให้สิทธิ์: ติ๊ก **ALL PRIVILEGES** → **Make Changes**

> จดไว้ 3 อย่าง: ชื่อฐานข้อมูล, ชื่อผู้ใช้ฐานข้อมูล, รหัสผ่าน (ใช้ในขั้นที่ 5)

## ขั้นที่ 3 — อัปโหลดไฟล์

1. cPanel → **File Manager** → เปิดโฟลเดอร์ `public_html/crmsure.amnsure.co.th`
2. มุมขวาบน **Settings** → ติ๊ก **Show Hidden Files (dotfiles)** → Save (เพื่อให้เห็นไฟล์ `.htaccess`)
3. กด **Upload** → เลือก `amnsure-crm-v1.0.0.zip` → รออัปโหลดเสร็จ → กลับไปที่โฟลเดอร์
4. คลิกขวาที่ไฟล์ zip → **Extract** → ให้แตกไฟล์ลงใน `public_html/crmsure.amnsure.co.th` → เสร็จแล้วลบไฟล์ zip ทิ้งได้
5. ตรวจว่าในโฟลเดอร์มี `index.php`, `install.php`, `.htaccess`, `app/`, `assets/`, `storage/` **อยู่ชั้นเดียวกับ `php.ini` เดิม** (ถ้าไปอยู่ในโฟลเดอร์ย่อยอีกชั้น ให้ย้ายขึ้นมา)

## ขั้นที่ 4 — เปิด HTTPS (สำคัญ ควรทำก่อนติดตั้ง)

1. cPanel → **SSL/TLS Status**
2. ติ๊ก `crmsure.amnsure.co.th` → **Run AutoSSL** → รอจนขึ้นแม่กุญแจสีเขียว (บางโฮสต์ใช้เวลาไม่กี่นาที)

## ขั้นที่ 5 — รันตัวติดตั้ง

1. เปิดเบราว์เซอร์ไปที่ **https://crmsure.amnsure.co.th/install.php**
2. ส่วน "ตรวจสอบเซิร์ฟเวอร์" ต้องเป็น ✅ ทั้งหมด (⚠️ = แนะนำ ไม่บังคับ)
3. กรอกฐานข้อมูล: Host = `localhost`, ชื่อฐานข้อมูล / ผู้ใช้ / รหัสผ่าน จากขั้นที่ 2
4. กรอกบัญชี GM คนแรก: ชื่อ-นามสกุล, ชื่อผู้ใช้ (เช่น `gm`), รหัสผ่าน (อย่างน้อย 10 ตัว มีตัวอักษรและตัวเลข)
5. กด **ติดตั้ง** → ขึ้น "✅ ติดตั้งสำเร็จ"

ตัวติดตั้งใช้ได้ครั้งเดียว หลังติดตั้งแล้วจะไม่ทำอะไรอีก (จะลบไฟล์ `install.php` ทิ้งด้วยก็ได้)

## ขั้นที่ 6 — บังคับใช้ HTTPS

File Manager → คลิกขวา `.htaccess` → **Edit** → เลื่อนลงล่างสุด ลบเครื่องหมาย `#` หน้า 3 บรรทัดนี้ → Save

```
RewriteEngine On
RewriteCond %{HTTPS} !=on
RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
```

## ขั้นที่ 7 — สร้างบัญชีพนักงาน

1. เข้า https://crmsure.amnsure.co.th ด้วยบัญชี GM
2. เมนู **ผู้ใช้และสิทธิ์** → **+ เพิ่มผู้ใช้** → กรอกชื่อ, ชื่อผู้ใช้, เลือก role
3. ระบบสร้างรหัสผ่านชั่วคราวให้ → ส่งชื่อผู้ใช้ + รหัสชั่วคราวให้พนักงาน (พนักงานต้องตั้งรหัสใหม่เองตอนเข้าครั้งแรก)

| Role | ใช้กับ |
|---|---|
| ผู้จัดการทั่วไป (GM) | GM — เห็นทุกอย่าง อนุมัติการซื้อ |
| ผู้บริหาร (Management) | ทีมผู้บริหาร — ดูได้ทุกอย่างรวมตัวเลขการเงิน แต่แก้ไม่ได้ |
| ผู้อำนวยการฝ่ายขาย / ฝ่ายบริการ | หัวหน้าฝ่าย |
| ผู้ประสานงานขาย / พนักงานขาย / วิศวกรบริการ / การตลาด | พนักงาน |
| ผู้ดูแลระบบ (Admin) | คนดูแล IT — จัดการผู้ใช้ได้ แต่ไม่เห็นตัวเลขการเงิน |

แนะนำให้มีบัญชีที่เป็น GM หรือ Admin อย่างน้อย **2 คน** เผื่อคนหนึ่งลืมรหัสผ่าน (ปุ่มรีเซ็ตรหัสอยู่ในหน้าแก้ไขผู้ใช้)

## ขั้นที่ 8 (ถ้าต้องแนบไฟล์ใหญ่) — ขนาดไฟล์อัปโหลด

ค่าเริ่มต้นของโฮสต์มักจำกัดไฟล์ละ 2 MB
1. cPanel → **MultiPHP INI Editor** → เลือก `crmsure.amnsure.co.th`
2. ตั้ง `upload_max_filesize` = `16M` และ `post_max_size` = `20M` → Apply
3. ในระบบ CRM: เมนู **ตั้งค่า** → "ขนาดไฟล์แนบสูงสุด" (ค่าเริ่มต้น 10 MB)

พื้นที่โฮสต์มี 2 GB — วิดีโอแนะนำให้แนบเป็นลิงก์ (Google Drive / YouTube แบบไม่เปิดสาธารณะ) แทนการอัปโหลดไฟล์

## สำรองข้อมูล (Backup) — ทำอย่างน้อยสัปดาห์ละครั้ง

ข้อมูลอยู่ 2 ที่ ต้องสำรองทั้งคู่:

1. **ฐานข้อมูล**: cPanel → **Backup** → หัวข้อ "Download a MySQL Database Backup" → คลิก `amnsureco_crm`
2. **ไฟล์แนบ + ไฟล์ตั้งค่า**: File Manager → โฟลเดอร์ `crmsure.amnsure.co.th` → เลือก `storage` และ `app/config.php` → **Compress** → ดาวน์โหลดไฟล์ zip

ถ้าโฮสต์มี **JetBackup** ใช้กู้คืนย้อนหลังได้อีกทาง

## อัปเดตเป็นเวอร์ชันใหม่

อัปโหลดไฟล์เวอร์ชันใหม่ทับได้เลย **ยกเว้น** `app/config.php` และโฟลเดอร์ `storage/` (ห้ามลบ/ทับ 2 อย่างนี้) — สำรองข้อมูลก่อนอัปเดตทุกครั้ง

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| เปิดเว็บแล้วเห็น "Index of /" | ยังไม่ได้แตกไฟล์ หรือไฟล์ไปอยู่ในโฟลเดอร์ย่อย (ดูขั้นที่ 3 ข้อ 5) |
| ตัวติดตั้งขึ้น ❌ PHP เวอร์ชัน | ทำขั้นที่ 1 ใหม่ |
| "เชื่อมต่อฐานข้อมูลไม่ได้" | ตรวจชื่อฐานข้อมูล/ผู้ใช้ต้องมีคำนำหน้า `amnsureco_` และให้สิทธิ์ ALL PRIVILEGES แล้ว |
| หน้า "ระบบขัดข้อง" พร้อมรหัส | ดูไฟล์ `storage/logs/app-ปี-เดือน.log` ค้นหารหัสนั้น แล้วส่งข้อความให้ผู้พัฒนา |
| อัปโหลดไฟล์ไม่ได้ / "ไฟล์ใหญ่เกิน" | ทำขั้นที่ 8 |
| ใส่รหัสผิดหลายครั้งแล้วเข้าไม่ได้ | รอ 15 นาที หรือให้ GM/Admin รีเซ็ตรหัสให้ |
| ลืมรหัส GM และไม่มี Admin คนอื่น | ติดต่อผู้พัฒนา (ต้องแก้ผ่านฐานข้อมูล) |

## ความปลอดภัยที่ระบบทำให้แล้ว

- ต้องล็อกอินทุกหน้า ไม่มีหน้าสมัครสมาชิก บัญชีสร้างโดย GM/Admin เท่านั้น
- สิทธิ์ตรวจที่ฝั่ง server ทุกครั้ง; ตัวเลขต้นทุน/Valuation/GP ถูกตัดออกก่อนส่งถึงเบราว์เซอร์ของคนที่ไม่มีสิทธิ์
- ปิดบัญชี/เปลี่ยนสิทธิ์ มีผลทันที; ใส่รหัสผิด 5 ครั้งล็อก 15 นาที; ไม่ใช้งาน 8 ชั่วโมงออกจากระบบเอง
- โฟลเดอร์ `app/` (โค้ด+รหัสฐานข้อมูล) และ `storage/` (ไฟล์แนบ) เปิดผ่านเว็บตรง ๆ ไม่ได้ — ไฟล์แนบดาวน์โหลดได้เฉพาะผู้มีสิทธิ์
- ทุกการเปลี่ยนแปลงราคา ต้นทุน การอนุมัติ สถานะ และเจ้าของเครื่อง ถูกบันทึกใน Audit log (ค่าเก่า → ค่าใหม่)
- ไม่ให้ Google เก็บหน้าเว็บ (noindex)
