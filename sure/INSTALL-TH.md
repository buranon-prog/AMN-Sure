# คู่มือติดตั้ง AMN SURE บน cPanel (subdomain crmsure.amnsure.co.th)

ระบบ ลูกค้า · สาขา · เครื่อง · การขาย · บริการ ตามสเปก `SURE-ClaudeCode-Prompt.md`
ใช้เวลาประมาณ 20 นาที ทำผ่านหน้า cPanel ทั้งหมด ไม่ต้องใช้ SSH/Terminal

## สิ่งที่ต้องมี

- subdomain `crmsure.amnsure.co.th` (โฟลเดอร์ `public_html/crmsure.amnsure.co.th`)
- PHP 7.4 ขึ้นไป (แนะนำ 8.1 หรือใหม่กว่า) และ MySQL/MariaDB ของ cPanel
- ไฟล์ `amnsure-sure-v1.0.0.zip`

> **ถ้าเคยอัปโหลด CRM v1 (`amnsure-crm-v1.0.0.zip`) ไว้ใน subdomain นี้แล้ว** — AMN SURE จะมาแทนที่บน subdomain เดียวกัน
> ให้ทำขั้นที่ 0 ก่อน ส่วนฐานข้อมูลของ CRM v1 (`amnsureco_crm`) ไม่ถูกแตะ — ระบบใหม่ใช้ฐานข้อมูลแยก

---

## ขั้นที่ 0 — (เฉพาะกรณีมี CRM v1 อยู่แล้ว) ย้ายไฟล์เดิมออก

1. cPanel → **File Manager** → เปิด `public_html/crmsure.amnsure.co.th`
2. **Settings** (มุมขวาบน) → ติ๊ก **Show Hidden Files (dotfiles)** → Save
3. สร้างโฟลเดอร์ใหม่นอก public_html เช่น `/home/amnsureco/crm-v1-backup` แล้วย้าย (Move) ไฟล์ทั้งหมดของ CRM v1 ไปไว้ที่นั่น
   (`index.php`, `install.php`, `.htaccess`, `robots.txt`, `app/`, `assets/`, `storage/`) — **เหลือ `php.ini` ของโฮสต์ไว้ที่เดิม**

## ขั้นที่ 1 — ตั้งเวอร์ชัน PHP ของ subdomain

1. cPanel → **MultiPHP Manager** (หรือ **Select PHP Version**)
2. ติ๊ก `crmsure.amnsure.co.th` → เลือก PHP **8.1 ขึ้นไป** → **Apply**
3. ถ้าใช้หน้า **Select PHP Version** ให้ตรวจว่า extension `pdo_mysql` และ `mbstring` ถูกติ๊กอยู่

## ขั้นที่ 2 — สร้างฐานข้อมูลใหม่

1. cPanel → **MySQL® Database Wizard**
2. ตั้งชื่อฐานข้อมูล `sure` → ได้ชื่อเต็ม `amnsureco_sure`
3. สร้างผู้ใช้ฐานข้อมูล `sureuser` → ได้ `amnsureco_sureuser` กด **Password Generator** แล้ว **คัดลอกรหัสผ่านเก็บไว้**
4. หน้าให้สิทธิ์: ติ๊ก **ALL PRIVILEGES** → **Make Changes**

> จดไว้ 3 อย่าง: ชื่อฐานข้อมูล, ชื่อผู้ใช้ฐานข้อมูล, รหัสผ่าน (ใช้ในขั้นที่ 5)

## ขั้นที่ 3 — อัปโหลดไฟล์

1. File Manager → เปิด `public_html/crmsure.amnsure.co.th` (เปิด Show Hidden Files ไว้ เพื่อให้เห็น `.htaccess`)
2. **Upload** → เลือก `amnsure-sure-v1.0.0.zip` → รอเสร็จ → กลับไปที่โฟลเดอร์
3. คลิกขวาที่ zip → **Extract** → แตกลงใน `public_html/crmsure.amnsure.co.th` → ลบไฟล์ zip ทิ้งได้
4. ตรวจว่า `index.php`, `install.php`, `.htaccess`, `app/`, `assets/`, `storage/` อยู่ **ชั้นเดียวกับ `php.ini`** (ถ้าไปอยู่ในโฟลเดอร์ย่อยอีกชั้น ให้ย้ายขึ้นมา)

## ขั้นที่ 4 — เปิด HTTPS (ทำก่อนติดตั้ง)

cPanel → **SSL/TLS Status** → ติ๊ก `crmsure.amnsure.co.th` → **Run AutoSSL** → รอจนขึ้นแม่กุญแจสีเขียว

## ขั้นที่ 5 — รันตัวติดตั้ง

1. เปิด **https://crmsure.amnsure.co.th/install.php**
2. ส่วน "ตรวจสอบเซิร์ฟเวอร์" ต้องเป็น ✅ ทั้งหมด
3. ฐานข้อมูล: Host = `localhost`, ชื่อฐานข้อมูล / ผู้ใช้ / รหัสผ่าน จากขั้นที่ 2
4. บัญชี **Manager** คนแรก: ชื่อ-นามสกุล, ชื่อผู้ใช้ (เช่น `manager`), รหัสผ่าน (อย่างน้อย 10 ตัว มีตัวอักษรและตัวเลข)
5. กด **ติดตั้ง** → ขึ้น "✅ ติดตั้งสำเร็จ"

ตัวติดตั้งสร้างตารางทั้งหมด + รายการตัวเลือกตามสเปกหัวข้อ 10 + VAT 7% และใช้ได้ครั้งเดียว (ลบไฟล์ `install.php` ทิ้งหลังติดตั้งก็ได้)
ระบบเริ่มต้นแบบ **ว่าง ไม่มีข้อมูลลูกค้า** — ข้อมูลตัวอย่างในสเปกหัวข้อ 11 ใช้สำหรับทดสอบเท่านั้น ไม่รวมอยู่ในไฟล์ zip

## ขั้นที่ 6 — บังคับใช้ HTTPS

File Manager → คลิกขวา `.htaccess` → **Edit** → เลื่อนลงล่างสุด ลบ `#` หน้า 3 บรรทัดนี้ → Save

```
RewriteEngine On
RewriteCond %{HTTPS} !=on
RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
```

## ขั้นที่ 7 — ตั้งค่าเริ่มต้นและสร้างบัญชีพนักงาน

1. เข้า https://crmsure.amnsure.co.th ด้วยบัญชี Manager
2. เมนู **รายการตัวเลือก & ค่าตั้งต้น** → การ์ด "พนักงาน (แก้เป็นชื่อจริง)" → แก้ `Sales Executive 1` ฯลฯ เป็นชื่อพนักงานจริง
   (ใช้ใน dropdown Sales / วิศวกร / ผู้บันทึก) — แก้ก่อนเริ่มบันทึกข้อมูล เพราะแถวที่บันทึกแล้วจะเก็บชื่อเดิมไว้
3. เมนู **บัญชีผู้ใช้** → **+ เพิ่มผู้ใช้** → กรอกชื่อ, ชื่อผู้ใช้, เลือกประเภทบัญชี และสิทธิ์ SURE

| ประเภทบัญชี | เห็น / ทำได้ |
|---|---|
| **Manager** | ทุกอย่าง: ต้นทุนเครื่อง, กำไรรายการขาย, สรุป, คอลัมน์สรุปลูกค้า, export ทุกตาราง, แก้รายการตัวเลือก + VAT, ลบแถว, จัดการบัญชี |
| **พนักงาน + ดู** | ดูตาราง ลูกค้า สาขา ติดตามลูกค้า เครื่อง การขาย รับชำระเงิน บริการ + หน้าค้นหา + export ตารางเหล่านี้ |
| **พนักงาน + ดู + เพิ่ม/แก้ไข** | เพิ่ม/แก้ไขตารางข้างต้น · **ลบไม่ได้** (ใช้การเปลี่ยนสถานะแทน) |
| **พนักงาน ไม่มีสิทธิ์ SURE** | เข้าสู่ระบบได้ แต่ไม่เห็นเมนูและเปิดหน้าใดไม่ได้ |

พนักงานทุกแบบ **ไม่เห็นต้นทุน กำไร GP หน้าสรุป และหน้ากำไรรายการขาย** — ระบบตัดข้อมูลเหล่านี้ทิ้งที่ server ก่อนส่งถึงเบราว์เซอร์ (รวมถึงไฟล์ export)

ระบบสร้างรหัสผ่านชั่วคราวให้ → ส่งชื่อผู้ใช้ + รหัสชั่วคราวให้พนักงาน (ต้องตั้งรหัสใหม่เองตอนเข้าครั้งแรก)
แนะนำให้มีบัญชี Manager อย่างน้อย **2 คน** เผื่อคนหนึ่งลืมรหัสผ่าน (ปุ่มรีเซ็ตรหัสอยู่ในหน้าแก้ไขผู้ใช้)

## ลำดับการกรอกข้อมูล

ลูกค้า → สาขา → เครื่อง → การขาย → รับชำระเงิน / บริการ (ติดตามลูกค้าบันทึกได้ตั้งแต่มีลูกค้า)
ฟอร์มเพิ่มข้อมูลเติม **รหัสถัดไป** ให้อัตโนมัติ — กดบันทึกได้เลย ระบบตรวจรูปแบบและรหัสซ้ำอีกครั้งตอนบันทึก

## สำรองข้อมูล (Backup) — ทำอย่างน้อยสัปดาห์ละครั้ง

1. **ฐานข้อมูล**: cPanel → **Backup** → "Download a MySQL Database Backup" → คลิก `amnsureco_sure`
2. **ไฟล์ตั้งค่า**: File Manager → ดาวน์โหลด `app/config.php` (มีรหัสฐานข้อมูล — เก็บเป็นความลับ)

ถ้าโฮสต์มี **JetBackup** ใช้กู้คืนย้อนหลังได้อีกทาง

## อัปเดตเป็นเวอร์ชันใหม่

สำรองข้อมูลก่อน แล้วอัปโหลดไฟล์เวอร์ชันใหม่ทับได้เลย **ยกเว้น** `app/config.php` และโฟลเดอร์ `storage/` (ห้ามลบ/ทับ)

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| เปิดเว็บแล้วเห็น "Index of /" | ยังไม่ได้แตกไฟล์ หรือไฟล์ไปอยู่ในโฟลเดอร์ย่อย (ขั้นที่ 3 ข้อ 4) |
| ตัวติดตั้งขึ้น ❌ PHP เวอร์ชัน | ทำขั้นที่ 1 ใหม่ |
| "เชื่อมต่อฐานข้อมูลไม่ได้" | ชื่อฐานข้อมูล/ผู้ใช้ต้องมีคำนำหน้า `amnsureco_` และให้สิทธิ์ ALL PRIVILEGES แล้ว |
| "ฐานข้อมูลนี้มีตารางของระบบอยู่แล้ว" | ใช้ฐานข้อมูลใหม่ (`amnsureco_sure`) ไม่ใช้ร่วมกับฐานข้อมูลของ CRM v1 |
| หน้า "ระบบขัดข้อง" พร้อมรหัส | ดูไฟล์ `storage/logs/app-ปี-เดือน.log` ค้นหารหัสนั้น แล้วส่งให้ผู้พัฒนา |
| ใส่รหัสผิดหลายครั้งแล้วเข้าไม่ได้ | รอ 15 นาที หรือให้ Manager รีเซ็ตรหัสให้ |
| ปฏิทินเลือกวันที่แสดงเป็น เดือน/วัน/ปี | ขึ้นกับภาษาของเบราว์เซอร์ — ใต้ช่องวันที่ระบบแสดง วว/ดด/ปปปป ให้เสมอ และตาราง/รายงานแสดง วว/ดด/ปปปป ทุกที่ |

## ความปลอดภัยที่ระบบทำให้แล้ว

- ต้องล็อกอินทุกหน้า ไม่มีหน้าสมัครสมาชิก บัญชีสร้างโดย Manager เท่านั้น
- สิทธิ์ตรวจที่ฝั่ง server ทุกหน้า ทุก action และทุก export; ข้อมูลพนักงานคำนวณโดยไม่อ่านตารางต้นทุนเลย
- ปิดบัญชี/เปลี่ยนสิทธิ์/รีเซ็ตรหัส มีผลทันที; ใส่รหัสผิด 5 ครั้งล็อก 15 นาที; ไม่ใช้งาน 8 ชั่วโมงออกจากระบบเอง
- ทุกแถวเก็บ "บันทึกโดย / แก้ไขล่าสุดโดย" พร้อมเวลา
- โฟลเดอร์ `app/` (โค้ด + รหัสฐานข้อมูล) และ `storage/` เปิดผ่านเว็บตรง ๆ ไม่ได้; ไม่ให้ Google เก็บหน้าเว็บ (noindex)
